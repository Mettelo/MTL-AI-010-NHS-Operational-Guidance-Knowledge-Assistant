# 06 — Evaluation

Evaluate the complete RAG system.

Required dimensions:
- retrieval quality;
- answer correctness;
- groundedness;
- citation correctness;
- refusal quality.

Recommended reporting:
- Recall@k / Hit Rate@k;
- answer score rubric;
- groundedness rate;
- citation support rate;
- false-answer rate on unanswerable questions.

Include qualitative error analysis.

Do not rely only on automated LLM-as-judge scoring. Human review should be part of the evaluation.
