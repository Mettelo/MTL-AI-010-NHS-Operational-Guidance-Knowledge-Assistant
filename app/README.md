# Application Interface

Provide a lightweight free/local interface.

Acceptable:
- CLI;
- Streamlit;
- Gradio.

Minimum user experience:
1. user enters a question;
2. system retrieves evidence;
3. system returns a concise answer;
4. supporting citations are visible;
5. insufficient-evidence responses are clearly shown.

Optional:
- show retrieved passages;
- retrieval confidence/similarity;
- source filtering;
- evaluation/debug mode.

The interface is not a substitute for evaluation.
