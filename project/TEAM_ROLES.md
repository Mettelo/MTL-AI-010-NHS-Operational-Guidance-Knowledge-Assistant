# Suggested Team Roles

Recommended team size: **3–5 members**.

## Knowledge / Ingestion Engineer
Owns:
- source manifest;
- acquisition;
- parsing;
- cleaning;
- metadata.

## Retrieval Engineer
Owns:
- chunking experiments;
- embeddings;
- vector store;
- retrieval;
- optional hybrid/reranking.

## LLM / RAG Engineer
Owns:
- generation prompt;
- local model integration;
- grounded-answer logic;
- citations;
- refusal behaviour.

## Evaluation & Safety Engineer
Owns:
- evaluation dataset;
- retrieval metrics;
- answer-quality evaluation;
- hallucination tests;
- prompt-injection tests.

## AI Product / Technical Lead
May be combined with another role.

Owns:
- problem framing;
- end-to-end architecture;
- interface;
- integration;
- reproducibility;
- final QA/handover.

Every member must make substantive technical contributions.
