## Working agreement
Teams should:
- create issues for substantive work;
- use scoped branches;
- make meaningful commits;
- open pull requests;
- review each other's work;
- avoid one final bulk upload.

## Example branches
- `feature/nhs-source-ingestion`
- `experiment/chunking-strategy`
- `feature/vector-retrieval`
- `feature/local-llm-rag`
- `evaluation/rag-benchmark`
- `safety/prompt-injection-tests`

## Example commits
- `feat: add NHS source manifest pipeline`
- `experiment: compare heading-aware chunking`
- `feat: implement FAISS retrieval`
- `eval: add retrieval recall benchmark`
- `fix: refuse unsupported knowledge questions`
- `test: add prompt injection cases`
